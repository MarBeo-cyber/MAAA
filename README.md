# MAAA v0.3 Integrated Release

**Metacognitive Autopoietic Adaptive Agent**

This release restructures the MAAA as an architectural integration of the previous technical-informatics document v1.2 and the newer autopoietic ontology principle:

> Not a simulation of life, but a simulation of the functions that make life capable of persisting, learning and cooperating.

## What is included

- Five-layer architecture
- Edge-first technical stack
- Real-time processing pipeline
- Risk Estimation Engine
- Human State Monitoring
- Symbiotic Regulatory Engine
- Autopoietic Continuity and Failsafe Engine
- Episodic memory with conservative WAAA-inspired pruning
- Demo CLI
- HTML/SVG sensory demo
- Tests

## Quickstart

```bash
python examples/run_demo.py
python -m pytest tests -q
```

## Scope

This prototype is a software architecture demonstrator. It does not control real safety equipment, does not diagnose human states, and must not be used for real emergency guidance without validation and certification.
