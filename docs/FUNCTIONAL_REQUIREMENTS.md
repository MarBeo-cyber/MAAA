# Functional Requirements

| ID | Requirement |
|---|---|
| FR-01 | Acquire multimodal wearable inputs from AR, IMU, audio and optional eye tracking |
| FR-02 | Build a scene graph of detected hazards, paths and objects |
| FR-03 | Estimate structural, environmental and walkability risks |
| FR-04 | Estimate human cognitive entropy from stress/load proxies |
| FR-05 | Produce short multimodal guidance plans |
| FR-06 | Apply relevance, timing, brevity and urgency filters |
| FR-07 | Preserve episodic continuity and avoid contradictory guidance |
| FR-08 | Enter failsafe mode under sensor degradation, battery collapse or excessive latency |
| FR-09 | Operate offline-first for critical functions |
| FR-10 | Support mesh/multi-agent extension in later releases |
