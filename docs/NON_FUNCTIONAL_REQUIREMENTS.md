# Non-Functional Requirements

| ID | Requirement | Target |
|---|---|---|
| NFR-01 | Tier-0 voice/AR/haptic guidance latency | < 50 ms |
| NFR-02 | Tier-1 cognitive loop latency | < 200 ms |
| NFR-03 | Offline critical operation | mandatory |
| NFR-04 | Raw video cloud upload | forbidden by default |
| NFR-05 | Human override | mandatory |
| NFR-06 | Output brevity | 7-9 words in emergency mode |
| NFR-07 | Graceful degradation | audio-only / overlay-only / failsafe |
| NFR-08 | Auditability | every guidance event logged |
